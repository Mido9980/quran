# تشغيل المشروع على SPCK Editor

المشروع HTML + CSS + JS عادي، من غير أي بناء أو حزم. يعني يفتح في SPCK Editor ويشتغل على طول.

## أول مرة: ربط جيت هب
1. نزّل *SPCK Editor* من جوجل بلاي.
2. افتح التطبيق ← من القائمة اختار *Git* ← *Clone Repository*.
3. اختار GitHub وحدد *Personal Access Token* (مش باسورد).
4. ازاي تجيب التوكن: افتح https://github.com/settings/tokens ← Generate new token (classic) ← علّم على `repo` وبس ← Generate ← انسخ التوكن.
5. الصق التوكن في SPCK، واختار المستودع `Mido9980/quran`.
6. Clone. الملفات هتنزل عندك وتبقى قابلة للتعديل.

## المعاينة أثناء التعديل
- من SPCK اضغط على `index.html` ← Preview.
- SPCK بيشغّل سيرفر محلي على localhost، فالأوف لاين والسيرفس وركر بيشتغلوا عادي في المعاينة.
- لو ظهرت شاشة بيضاء، اتأكد إنك بتعاين من جذر المشروع مش من داخل مجلد.

## النشر بعد التعديل
1. اعمل Commit برسالة واضحة (مثال: تحسين شكل قائمة السور).
2. اعمل Push على فرع `main`.
3. جيت هب بيدجز بينشر تلقائياً في دقيقة تقريباً: https://mido9980.github.io/quran/

## التنسيق بيننا
- أنا بعدّل وأرفع على نفس الفرع `main`.
- قبل ما تعدّل، اعمل *Pull* في SPCK عشان تاخد آخر نسخة.
- بعد ما تخلص، اعمل Push.
- لو حصل تعارض، متكتبش فوقه: ابعتلي اسم الملف وأنا أدمج التعديلين.
